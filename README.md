# AR名刺 — NO FOOTBALL

紙の名刺にスマホをかざすと、中央に3Dロゴが浮かび上がり、
その周りに各事業のメニューが展開。タップすると各サイトへ飛びます。
**アプリのインストールは不要**、ブラウザだけで動きます。

```
① 名刺を受け取る → ② QRを読む / カメラをかざす
   → ③「田畑 辰朗」の3Dロゴ＋事業メニューが出現 → ④ タップして各ページへ
```

現在のメニュー： **NO FOOTBALL** / **カタチラボ** / **3D戦術ボード**

## いま入っているもの

| ファイル | 中身 |
|---|---|
| `index.html` | AR本体（これ1枚で完結。ビルド不要） |
| `targets/targets.mind` | 名刺の認識データ（**生成済み**・判定◎） |
| `assets/名刺.png` | 名刺デザインの元画像 |
| `assets/名刺_marker.png` | マーカー生成に使った画像（縁を除去し1024pxへ） |
| `assets/logo.svg` | 中央に立体表示するロゴ（任意） |
| `assets/logos/*.png` | 各事業のアイコン（`nof` / `katachi` / `tactics`・生成済み） |
| `contact.vcf` | 「連絡先を保存」で配布されるvCard |
| `tools/compile.html` | **マーカー判定ツール**（`targets.mind` の生成＋認識できるか判定） |

技術構成： **MindAR.js 1.2.5**（画像認識・MIT・無料） + **Three.js 0.160**。
どちらもCDN読み込みなので `npm install` は不要です。

## 本番セットアップ

### 1. 名刺画像 → `targets.mind`（**この名刺では作成済み**）

`assets/名刺.png` を判定ツールにかけた結果：

| 指標 | 値 | 判定 |
|---|---|---|
| 総合判定 | **◎** | 安定して認識できる見込み |
| 検出用の特徴点 | 2171 | ◎の基準（400以上）を大きく超える |
| 分布カバー率 | 88%（16分割中14マス） | 良好 |
| 縦横比 | 1.652（名刺 1.655） | ほぼ一致 |
| スケール別 | 9段階すべてに点あり（最小でも67） | 遠くからでも認識できる |

特徴点は NFロゴ・NO FOOTBALL・氏名・会社情報・QR・右上タグライン・
SCAN TO AR に広く分布。空白なのは**中央右の余白の2マスのみ**でした。
QRコードが特徴点の大きな供給源になっています。

#### ⚠️ デザインを変えたら必ず作り直す

`targets.mind` は**画像そのものが基準**です。次の場合は再生成が必要です。

- QRコードの内容を差し替えた（公開URLが決まったら必ず発生します）
- 住所・TEL・URLの伏せ字（`000-0000` など）を実際の値に入れ替えた
- ロゴや文字の位置・サイズを少しでも動かした

#### 作り直す手順

```bash
npx serve .
```

→ **`http://localhost:3000/tools/compile.html`** に名刺の表面画像をドロップ

出力されるもの：

- **判定（◎ / ○ / △ / ✕）**、検出用・追従用の特徴点、分布カバー率
- **特徴点の可視化**（どこに点が立っているかを名刺の上に重ねて表示）
- **`targets.mind` のダウンロード** → `targets/targets.mind` に置く

> 解析には数十秒〜数分かかります。タブを裏に回すとブラウザが処理を絞るので、
> **開いたまま待って**ください。
>
> 公式のオンライン版でも同じことができます：
> https://hiukim.github.io/mind-ar-js-doc/tools/compile

**判定の目安**

| 判定 | 条件 | 意味 |
|---|---|---|
| ◎ | 検出用 400以上 かつ カバー率 75%以上 | 安定して認識できる見込み |
| ○ | 検出用 200以上 かつ カバー率 50%以上 | 実用ライン。斜め・暗所でやや弱い |
| △ | 検出用 100以上 | 不安定。情報量を足すことを推奨 |
| ✕ | それ未満 | このままでは認識が困難 |

数値はあくまで目安です。**最終確認は必ず実機テスト**で行ってください。

### 2. `index.html` の設定を書き換える

ファイル上部の設定ブロックだけ触れば完成します。いま入っているのは3事業：

| メニュー | リンク先 |
|---|---|
| NO FOOTBALL | https://nofootball.base.shop/ |
| カタチラボ | https://tabatatsu109-netizen.github.io/katachilabo/index.html |
| 3D戦術ボード | https://grande-tactics-board.web.app/ |

```js
const MENU = [
  {
    id:    'nof',
    label: 'NO FOOTBALL',            // アイコン下の名前
    sub:   'ONLINE STORE',           // 小さい英字ラベル
    glyph: 'NF',                     // 画像が無いときに表示する文字
    img:   './assets/logos/nof.png', // 事業ロゴ（正方形・透過PNG 512px推奨）
    color: '#8fd3ff',                // アイコンの縁とグローの色
    url:   'https://nofootball.base.shop/',
    desc:  'タップしたときに出る説明文。',
  },
  // ... カタチラボ / 3D戦術ボード
];
```

- **メニューは何個でもOK**。配列に足せば自動で円形に再配置されます（3〜6個が見やすい）
- `img` が見つからないときは自動で `glyph` の文字表示にフォールバックします
- `plate: 'light'` を付けると円が白地になります（白背景のロゴ用。FUQAN BOARDで使用）
- 下部の常時ボタンは `UTIL`、中央ロゴは `LOGO`、配置は `LAYOUT` で調整
- 説明文（`desc`）は各サイトを見て仮で入れてあります。適宜書き換えてください

### 3. 中央の3Dロゴ

初期状態は **「田畑 辰朗」の文字を立体化**したものが浮かびます（クローム質感）。

日本語は Three.js の標準フォント形式（typeface.json）だと数MBの追加読み込みが必要なので、
**同じ字形の板を奥行き方向に30枚重ねて押し出しを再現**しています。
追加フォント無し・軽量で、日本語がそのまま立体になります。厚みは `LOGO.depth` で調整。

`assets/logo.svg` を置いた場合は、そちらのパスを本物の押し出しで3D化します。

> Illustratorから「SVG書き出し」→ テキストはアウトライン化、単色パスのみ、にしておくと確実です。

### 4. HTTPSで公開する

**カメラはHTTPS（またはlocalhost）でしか起動しません。**

- **Netlify Drop** … https://app.netlify.com/drop にフォルダをドラッグするだけ。最速
- **GitHub Pages / Cloudflare Pages / Vercel** … いずれも可

### 5. 名刺からの導線

公開URLを名刺の裏（またはロゴの下）に。

- **QRコード** … 確実・低コスト。「Scan to AR」の文言を添える
- **NFCタグ** … かざすだけ。名刺に貼り込む。単価は上がるが体験は最短

## 印刷するときの注意

デザイン自体は判定◎を取れています。残るリスクは**紙と印刷**です。

| | 理由 |
|---|---|
| ✅ **マット紙・上質紙を選ぶ** | 反射しない紙なら特徴点がそのまま残る |
| ❌ **光沢紙・PP加工・ラミネート** | 照明が写り込んで特徴点が消える。**避ける** |
| ❌ **箔押し・エンボス** | 同上。角度によって見え方が変わる |
| ✅ **QRは表面に残す** | 特徴点の大きな供給源になっている |
| ✅ **濃度を落とさない** | 薄いグレーで刷ると特徴点が減る |

**中央右の余白**（16分割中2マス）だけ特徴点がありません。
気になる場合は、ここに 3〜5% の薄いグレーで地紋やNFパターンを敷くと
見た目をほぼ変えずにカバー率を上げられます。ただし現状でも◎判定なので必須ではありません。

**印刷前に、試し刷り1枚で実機テストを必ず行ってください。**
画面上の判定と、実際の紙・照明での挙動は別物です。

## 座標系メモ（カスタマイズ用）

```
名刺の幅 = 1.0 / 高さ = 0.604（91:55）／ 中心が原点
X = 名刺の右方向, Y = 名刺の上方向, Z = 紙から手前に浮かぶ方向
```

`LAYOUT` の値：

| キー | 意味 | 初期値 |
|---|---|---|
| `ringRadius` | メニューの円の半径 | `0.66` |
| `iconSize` | アイコン板の幅 | `0.30` |
| `ringHeight` | メニューの浮き上がり | `0.30` |
| `logoHeight` / `logoScale` | ロゴの高さ / 大きさ | `0.30` / `0.58` |
| `orbitSpeed` | 0以外でメニューがゆっくり回る | `0.0` |

## 既知の制約

- iOS Safari は**ユーザー操作なしにカメラを起動できない** → スタート画面のボタンで対応済み
- LINE・Instagram のアプリ内ブラウザではカメラが使えないことがある
  → QRの遷移先に「Safari / Chrome で開いてください」の一文を添えると安全
- 暗所・浅い角度では追従が外れやすい
- 端末が古いとフレームレートが落ちる（MindARはCPU/WASM処理）
